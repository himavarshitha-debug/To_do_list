# 📝 To-Do List Management System

## 📌 Project Description

The **To-Do List Management System** is a simple Python-based task management application. It helps users organize and manage their daily activities, college work, projects, exams, and personal tasks.

Users can add tasks with a description, category, priority, due date, and reminder. Tasks can be searched, completed, deleted, and displayed based on their status or category.

## 🎯 Objectives

* Manage daily tasks efficiently.
* Organize tasks according to categories.
* Set task priorities.
* Set due dates and reminders.
* Track pending and completed tasks.
* Search for specific tasks.
* Delete unnecessary tasks.

## ⚙️ Main Features

### 1. Add Task

The user can add:

* Task name
* Description
* Category
* Priority
* Due date
* Reminder

### 2. View All Tasks

Displays all tasks along with their details and current status.

### 3. Mark Task as Completed

Changes a task status from **Pending** to **Completed**.

### 4. Delete Task

Removes an unwanted task from the system.

### 5. Search Task

Allows the user to search for a task using its name or keyword.

### 6. View Pending Tasks

Displays only tasks that are not completed.

### 7. View Completed Tasks

Displays tasks that have already been completed.

### 8. Task Categories

Tasks can be organized into categories such as:

* College
* Personal
* Project
* Exam
* Other

### 9. Reminders

The user can enter a reminder for each task. The reminder information can later be used to develop an automatic notification system.
